This is my first practical, self-directed project using **SAP Analytics Cloud (SAC)**.  
I built the project using the **SAC Free Trial**, starting with a raw supply-chain CSV dataset and working through dataset creation, validation, measures, calculations, story development and dashboard design.

The objective was to understand how raw operational data can be transformed into a simple, business-oriented analytical dashboard.

---

## 📊 Project Overview

| Area | Details |
|---|---|
| **Platform** | SAP Analytics Cloud (SAC) |
| **Project Type** | Self-directed hands-on learning project |
| **Data Source** | Supply-chain CSV dataset |
| **Dataset** | `SC_Inventory_Replenishment_Analytics` |
| **Output** | One-page Supply Chain Inventory & Replenishment Control Tower |
| **Business Areas** | Inventory, Demand, Replenishment, Supplier Performance |

The project follows a simple data-to-dashboard workflow:

**Raw Data → Dataset → Validation → Measures & Calculations → SAC Story → Dashboard**

---

## 🎯 Business Problem

Supply-chain data contains several connected signals that are useful when viewed together.

This dashboard was designed to explore questions such as:

- How much inventory is available?
- What demand is expected?
- Is inventory above the displayed reorder point?
- What is the typical order quantity?
- How long are suppliers taking?

The goal was not to build an enterprise supply-chain solution, but to use a realistic business context to learn how SAC can turn operational data into a structured analytical view.
